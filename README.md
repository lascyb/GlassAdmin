# GlassAdmin - 透明可视的后台框架
> 如果你厌倦了魔法般的封装，想要看清每一行代码的执行，GlassAdmin 是你的不二之选。
>
> 学习 GlassAdmin，你真正学会的是 Vue 3 和 ThinkPHP 8，而不是某个框架的特定语法。
>
> GlassAdmin 是一个基于 Vue 3 + ThinkPHP 8 + Element Plus + TypeScript 的现代化后台框架，专为追求代码透明度与控制权的开发者设计。

#### 🚀 技术栈原生体验

- ThinkPHP 8：保持原生开发体验
- Vue 3：现代化前端
- Element Plus：企业级UI组件
- TypeScript：全程类型支持


#### 📚 渐进式学习曲线

- 从原生开始：先学ThinkPHP/Vue/Element Plus，再学框架特性
- 透明文档：所有组件都有文档
- 逃生舱设计：随时可以绕过框架使用原生技术

#### 🌟 GlassAdmin - 没有黑魔法，只有好代码。

- 如果你厌倦了猜测框架在做什么，GlassAdmin 给你答案。
- 如果你想要理解每一行代码，GlassAdmin 给你清晰。
- 如果你追求长期可维护性，GlassAdmin 给你透明。
